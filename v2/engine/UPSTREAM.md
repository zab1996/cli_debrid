# Bundled mount engine: origin

This folder is a copy of cli_mount (mash2k3/decypharr), not a fork link.

- **Copied from:** `mash2k3/decypharr` branch `dev` at
  `d178589f72328099193dac1e1b449033f32a3ab7` (2026-11-12, "Merge pull request #23").
- **Module path:** unchanged (`github.com/sirrobot01/decypharr`), so upstream
  patches apply with `git apply`/`cherry-pick -X subtree=v2/engine`.
- **Not included:** `speed/mount-open-precache-and-pool-warmup` (unmerged at copy time).

## What was removed
| Removed | Why |
|---|---|
| `pkg/server` (web UI, auth, setup wizard, qBittorrent + SABnzbd emulation, WebDAV, repair/debug pages, webhooks) | replaced by `pkg/engineapi` |
| `pkg/stats` | only used by the old server |
| `pkg/mount/rclone`, `pkg/mount/external` | DFS is the only mount backend |
| `cmd/healthcheck`, `cmd/test-parser`, Node/Tailwind build, docs | not needed |

`pkg/arr` and `pkg/notifications` stay because the manager and storage use
their types; with no arr hosts or notification URLs configured they do nothing.

## What was added / changed
- `pkg/engineapi/api.go`: the localhost JSON API the Python app calls
  (`/status`, `/cache`, `/add`, `/entries/{id}`, `/entries/{id}/health`).
- `cmd/decypharr/main.go`: starts `engineapi` instead of `server`; DFS-only mount.

The engine's `config.json` is generated by `app/engine_config.py` on every start.

## Pulling in upstream fixes
```bash
cd decypharr && git format-patch -1 <sha> --stdout > /tmp/fix.patch
cd ../cli_debrid && git apply --directory=v2/engine /tmp/fix.patch
```
Skip hunks under the removed paths above.
